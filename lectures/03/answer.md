# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：  
  「AIE2026の講座の宿題にある『3レベル』とは何ですか？」と質問した。素のLLM（`app.ask`）は、講座の宿題について確認できていないまま、一般的な難易度別の課題を想定して回答した。一方、エージェント（`app.agent`）は、「基礎・実装・発展」の3レベルから1つ選び、どれか1つに取り組めば完了すると回答した。

- `--trace` で見えたツール呼び出し（ツール名と引数）：  
  「LoRA とQLoRAの違いは？」という質問に対して、`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` が各1回呼ばれた。

- 1つの質問での LLM 呼び出し回数（`requests`）：  
  上記の質問では `requests=2` だった。

- 追加したツールと、docstring に書いた説明：  
  新しいツールは追加していない。既存の `search_glossary` の docstring を変更し、ツールの呼ばれ方を比較した。

## 宿題

- 取り組んだレベル：基礎

- やったこと：  
  `app/agent.py` の `INSTRUCTIONS` または `app/tools.py` の `search_glossary` の docstring から、次の文を1つずつ削除した。それぞれ同じ質問「LoRA とQLoRAの違いは？」を `--trace` 付きで2回実行し、変更前と比べた。

  1. `INSTRUCTIONS` から「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。」を削除した。
  2. `INSTRUCTIONS` から「回答の最後に、関係する回（第N回）を示す。」を削除した。
  3. `search_glossary` の docstring から「query には調べたい用語を1つだけ入れる（例: "LoRA"）。」を削除した。

  さらに、1の結果を確かめるため、用語集の確認指示を削除した状態のまま、docstring から「答える前に使うこと。」も削除した。この追加実験でも、同じ質問を2回実行した。

- 結果：  
  変更前の2回の実行では、どちらも `LoRA` と `QLoRA` を別々に検索し、回答の最後に「関係する回：第2回」と記載された。回答の細かな表現には、変更前から違いがあった。

  1. 用語集の確認指示を削除しても、2回とも `LoRA` と `QLoRA` を別々に検索した。回答の書き出しなどには違いがあったが、変更前から表現には揺れがあるため、指示の削除による変化とは判断できなかった。
  2. 関係する回を示す指示を削除しても、2回とも検索の呼び出し方は変わらず、第2回への言及も残った。ただし、1回目は回答末尾の注記、2回目はLoRAの説明文の中に書かれた。変更前のように、2回とも末尾に独立した「関係する回：第2回」の行が付く形ではなかった。
  3. docstring の「用語を1つだけ」という説明を削除しても、2回とも `LoRA` と `QLoRA` を別々に検索した。2語をまとめて検索する動作は見られなかった。
  4. 追加実験では、用語集の確認指示と docstring の「答える前に使うこと。」を両方削除した。それでも2回とも `LoRA` と `QLoRA` を別々に検索し、`tool_calls=2`、`requests=2` だった。

- 気づき・疑問：  
  今回の質問では、用語集の確認指示と docstring の「答える前に使うこと。」を両方削除しても検索が行われた。そのため、docstring のその一文だけが検索を続けた理由ではないことが分かった。ツール名や、残っている「講座の用語集から用語を検索し…」という説明なども判断材料になり得るが、どれが検索につながったかまでは今回の実験では特定できない。また、関係する回を示す指示を削除すると、第2回への言及は残ったものの、その位置や形式は一定ではなかった。
